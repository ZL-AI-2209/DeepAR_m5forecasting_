Проект создан на основе https://github.com/husnejahan/DeepAR-pytorch
Основные изменения это:
1) работа с датасетом m5 forecasting (предобработка данных, формирование ковариант)
2) прогнозирование целочисленных данных (замена нормального распределения для прогноза на отрицательное биноминальное для учета хвостов) по мотивам оригинальной статьи
3) создана принципиально другая система генерации маски (запускается отдельно) на основе cusum алгоритма и соответствующей статьи на хабр: https://habr.com/ru/companies/magnit/articles/918928/
4) использование CRPS метрики как основной для замера точности прогноза на квантильной основе 

Подробнее про работу механизма генерации маски:
-каждый ряд проходит мультипликативную prophet декомпозицию для исключения сезонности 
-к каждому ряду заранее подбираются аналоги (на основе набора нормированных характеристик с определенными коэффициентами для контроля значимости на вектор) 
-формируются блоки с определяемым окном и шагом (самым оперативным 
-производится cusum детекция 
-с помощью подобранных аналогов статистический проводятся 4 вида проверка для фильтрации ложных срабатываний: 
      строится NB модель дискретности по аналогам, выявляется тренд дискретности и тренд значений и анализируется мин аналог
