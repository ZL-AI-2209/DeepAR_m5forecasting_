Проект создан на основе https://github.com/husnejahan/DeepAR-pytorch
Основные изменения это:
1) работа с датасетом m5 forecasting (предобработка данных, формирование ковариант, загрузчик) - с рассчетом на меньшую нагрузку на оперативную память
2) прогнозирование целочисленных данных (замена нормального распределения для прогноза на отрицательное биноминальное для учета хвостов) по мотивам оригинальной статьи
3) создание принципиально другая система генерации маски (запускается отдельно) на основе cusum алгоритма и соответствующей статьи на хабр: https://habr.com/ru/companies/magnit/articles/918928/
4) использование CRPS метрики как основной для замера точности прогноза на квантильной основе 

Подробнее про работу механизма генерации маски:
1) каждый ряд проходит мультипликативную prophet декомпозицию для исключения сезонности 
2) к каждому ряду заранее подбираются аналоги (на основе набора нормированных характеристик с определенными коэффициентами для контроля значимости на вектор) 
3) формируются блоки с определяемым окном и шагом (самым оптимальным для совмещения скорости и качества был 3 дня )
3) производится cusum детекция 
5) с помощью подобранных аналогов статистический проводятся 4 вида проверка для фильтрации ложных срабатываний: 
      строится NB модель дискретности по аналогам, выявляется тренд дискретности и тренд значений и анализируется мин аналог 

Детекция производится последовательно - более ранние обнаружения cusum нулей обрабатываются раньше
Это нужно потому что сама маска применяется динамический в процессе ее же формирования 
Аналоги подбираются соотвественно до момента детекции (в уже проверенной зоне )
